# Playwright SauceDemo Automation Framework

## Overview

Enterprise-style end-to-end automation framework built using Playwright and TypeScript for testing the SauceDemo e-commerce application.

## Tech Stack

* Playwright
* TypeScript
* Node.js
* Git
* GitHub Actions
* Page Object Model

## Features

* Page Object Model
* Cross-browser execution
* HTML reports
* Screenshots on failure
* Video on failure
* Trace collection
* Reusable test data

## Test Coverage

### Login

* Valid login
* Invalid credentials
* Locked user validation

## Run Tests

```bash
npx playwright test
```

## Open Report

```bash
npx playwright show-report
```
